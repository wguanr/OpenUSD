# 户型设计理念文档

## 核心设计原则

### 1. 动静分区
住宅户型的核心设计原则是动静分区。动区包括客厅、餐厅、厨房、玄关——这些是日常活动频繁、有噪音的区域。静区包括卧室、书房、儿童房——这些是需要安静休息的区域。合理的户型应当将动区和静区分离，减少相互干扰。

### 2. 功能聚合（湿区集中）
厨房和卫生间需要上下水管道和燃气管道，这些功能性房间应当集中布置在一起或相邻，共享管井。这不仅降低施工成本，也减少漏水风险。

### 3. 南北通透
中国住宅追求南北通透——南面房间（客厅、主卧）享受采光和通风，北面房间（厨房、次卫）有对流通风。走廊/过道连接南北区域。

### 4. 以客厅为核心
住宅户型中，客厅是家庭活动的中心。所有卧室围绕客厅布置，从客厅可以到达各个卧室，但卧室之间不直接相通。

## 各户型设计理念

### Studio（开间/公寓）—— 极致效率
**设计哲学**：空间效率最大化，一切为了节省面积。

**关键特征**：
- 开放式布局：客厅、卧室、餐厅合为一体，无隔墙
- 湿区紧凑集中：厨房和卫生间紧邻，共享一面管井墙
- 厨房采用开放式或半开放式（吧台隔断）
- 无独立玄关，入户即客厅
- 阳台兼具晾晒和休闲功能

**平面布局**：
```
南(+Z)
┌─────────────────┐
│                  │
│  客厅/卧室/餐厅   │  ← 南向大面积采光
│  (开放式一体)     │
│                  │
├────────┬────────┤
│ 厨房    │ 卫生间  │  ← 北向，湿区集中
│(开放式) │        │     共享管井墙
└────────┴────────┘
北(-Z)
```

**动静分区**：无明确分区（开间特性），通过家具摆放软分区。

---

### Compact 1BR（紧凑一居）—— 功能完整的最小住宅
**设计哲学**：在最小面积内实现完整的住宅功能分区。

**关键特征**：
- 明确的动静分区：客厅(动)+主卧(静)南向并排
- 湿区集中：厨房和卫生间在北侧，紧邻布置
- 玄关过渡：入户有短走廊过渡，不直接看到客厅
- 主卧独立：有门隔开，保证私密性

**平面布局**：
```
南(+Z)
┌──────────┬────────┐
│          │        │
│  客厅     │  主卧   │  ← 动区(客厅) | 静区(主卧)
│  (动区)   │ (静区)  │
│          │        │
├────┬─────┼────────┤
│厨房│玄关  │ 卫生间  │  ← 湿区集中(厨+卫)
│    │/走廊 │        │     玄关连接动静区
└────┴─────┴────────┘
北(-Z)
```

**动静分区**：左侧为动线（入户→玄关→客厅），右侧为静线（走廊→主卧）。厨卫紧邻共享管井。

---

### Standard 2BR（标准两居）—— 经典南北通透
**设计哲学**：南北通透、动静分离的经典家庭户型。

**关键特征**：
- 明确的动静分区：动区(客厅+餐厅+厨房)居中偏左，静区(卧室)分列两侧
- 客厅是交通核心：从客厅可达所有房间
- 餐客一体：客厅和餐厅连通，增大空间感
- 主卧套间（可选）：主卧可配独立卫生间
- 双卫设计（面积允许时）：主卫+公卫

**平面布局（变体A：经典南北通透）**：
```
南(+Z)
┌──────────┬──────────┐
│          │          │
│  客厅     │  主卧    │  ← 动区 | 静区
│  +餐厅   │          │
│  (动区)   │  (静区)  │
│          │          │
├────┬─────┼────┬─────┤
│厨房│走廊  │公卫 │次卧  │  ← 湿区集中 | 静区
│    │     │    │     │     厨+公卫共享管井
└────┴─────┴────┴─────┘
北(-Z)
```

**平面布局（变体B：横厅设计）**：
```
南(+Z)
┌────────────────────────┐
│                        │
│  客厅（横厅，大面宽）     │  ← 动区，超大采光面
│                        │
├──────┬────┬──────┬─────┤
│ 主卧  │厨房│ 公卫  │ 次卧 │  ← 静区|湿区|静区
│      │+餐 │      │     │     厨卫集中
└──────┴────┴──────┴─────┘
北(-Z)
```

**动静分区**：变体A为纵向分区（左动右静），变体B为横向分区（南动北静）。

### Comfort 3BR（舒适三居）—— 全功能家庭住宅
**设计哲学**：以客厅为核心的全功能家庭住宅，强调动静分区和主卧私密性。

**关键特征**：
- 严格动静分区：动区(客厅+餐厅+厨房)居中，静区(卧室群)分列两翼
- 客厅是家庭中心：所有卧室通过走廊连接客厅，但互不相通
- 主卧套间：主卧+主卫+衣帽间(可选)，独立私密
- 双卫标配：主卫(主卧内)+公卫(走廊旁)
- 餐厨一体：餐厅和厨房相邻，形成完整的烹饪-用餐动线
- 玄关缓冲：入户玄关不直对客厅

**平面布局（变体A：经典三室两厅两卫）**：
```
南(+Z)
┌────────┬──────────┬────────┐
│        │          │        │
│ 主卧    │  客厅     │ 次卧A  │  ← 静区|动区|静区
│ +主卫   │          │        │     主卧套间独立
│        │          │        │
├──┬─────┼────┬─────┼────────┤
│公│玄关  │餐厅 │ 厨房 │ 次卧B  │  ← 湿区|动区|静区
│卫│/走廊 │    │     │        │     厨卫+公卫共享管井
└──┴─────┴────┴─────┴────────┘
北(-Z)
```

**动静分区**：
- 动区（中央）：玄关→走廊→客厅→餐厅→厨房，形成完整的生活动线
- 静区（两翼）：左翼=主卧套间，右翼=次卧A+次卧B
- 主卧在最远端，最大限度保证私密性

### Luxury 4BR（豪华四居）—— 尊享空间
**设计哲学**：充裕的空间感，独立的功能区，每个家庭成员都有私密空间。

**关键特征**：
- 三段式动静分区：主卧翼(极静) | 公共区(动) | 次卧翼(静)
- 独立餐厅：不与客厅合并，有独立空间
- 双套间（可选）：主卧套间+长辈房套间
- 中西厨分离（可选）：中式厨房(封闭)+西式厨房(开放)
- 书房/多功能房：可作为第四卧室或书房
- 双阳台：客厅阳台+主卧阳台

**平面布局**：
```
南(+Z)
┌────────┬──────────┬────────┬───────┐
│        │          │        │       │
│ 主卧    │  客厅     │ 次卧A  │次卧B/ │
│ +主卫   │          │        │书房   │
│ +衣帽间 │          │        │       │
├──┬─────┼────┬─────┼────────┼───────┤
│公│玄关  │餐厅 │ 厨房 │ 次卧C  │ 长辈卫│
│卫│/走廊 │    │     │/儿童房 │(可选) │
└──┴─────┴────┴─────┴────────┴───────┘
北(-Z)
```

---

### Loft Duplex（复式/LOFT）—— 立体生活
**设计哲学**：上下分层实现彻底的动静分离，下层全部为动区，上层全部为静区。

**关键特征**：
- 彻底的动静分离：下层=动区(客厅+餐厅+厨房+卫生间)，上层=静区(卧室+书房)
- 挑高客厅：下层客厅层高4.5~5m，通透大气
- 湿区全部在下层：厨房+卫生间集中在下层北侧
- 楼梯作为空间焦点：连接上下层的楼梯是空间设计亮点
- 上层回廊：上层走廊可俯瞰下层客厅

**下层平面**：
```
南(+Z)
┌─────────────────┐
│                  │
│  客厅（挑高）     │  ← 动区核心
│  +餐厅           │
│                  │
├────────┬────────┤
│ 厨房    │ 卫生间  │  ← 湿区集中
│        │+楼梯间  │
└────────┴────────┘
北(-Z)
```

## 新增房间类型需求

基于以上设计理念，需要新增以下RoomType：
- ENTRANCE / FOYER：玄关
- STUDY：书房（独立于STORAGE）
- WALK_IN_CLOSET：衣帽间（主卧套间内）
- STAIRCASE：楼梯间（复式）

## 新增设计属性需求

Room需要新增属性：
- zone: "dynamic" | "static" | "wet" | "transition"  # 动静分区标记
- is_suite_part: bool  # 是否属于套间（主卧套间内的主卫/衣帽间）
- shares_pipe_wall: bool  # 是否共享管井墙
