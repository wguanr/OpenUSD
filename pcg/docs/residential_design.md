# 中国住宅小区商品房 PCG 生成器设计方案

## 1. 建筑形制分析

中国住宅小区商品房的核心特征：

### 1.1 建筑类型
| 类型 | 层数 | 特征 | 典型进深 | 典型面宽 |
|------|------|------|----------|----------|
| 多层板楼 | 6层 | 一梯两户，南北通透 | 10-13m | 每户8-12m |
| 小高层 | 11-18层 | 一梯两户/三户 | 12-15m | 每户8-14m |
| 高层板楼 | 18-33层 | 一梯两户/四户 | 12-16m | 每户8-14m |
| 高层塔楼 | 18-33层 | 两梯四户/六户 | 16-22m | 近正方形 |

### 1.2 户型单元特征
- 标准户型：一室一厅、两室一厅、三室两厅、四室两厅
- 每户有客厅大窗（南向）、卧室窗（南/北向）、厨房窗（北向）、卫生间小窗
- 南向阳台（客厅外挂阳台，1.5-2m深）
- 空调机位（外墙凹槽或外挂平台，每室一个）

### 1.3 公共区域
- 楼梯间 + 电梯间（核心筒）
- 走廊/过道
- 入户门厅

### 1.4 立面特征
- 南立面：大窗 + 阳台 + 空调机位
- 北立面：小窗（厨房/卫生间）+ 空调机位
- 山墙面（东西端）：少窗或无窗
- 底层：可能有底商（商铺）
- 顶层：坡屋顶或平顶 + 女儿墙

## 2. 生成逻辑架构

### 2.1 核心思路：单元拼接法

```
整栋建筑 = 底层(底商/架空层) + N × 标准层 + 顶层(屋顶)

标准层 = 核心筒 + 户型单元A × 1 + 户型单元B × 1 + ... (一梯N户)

户型单元 = 外墙壳体 + 窗户排布 + 阳台 + 空调机位
```

### 2.2 生成流程

1. **建筑轮廓**：根据板楼/塔楼类型生成矩形底面
2. **楼层划分**：底商层 + 标准住宅层 + 顶层
3. **户型单元排布**：沿南立面排列户型单元，计算每户的面宽
4. **核心筒放置**：在建筑中央放置楼梯间+电梯间
5. **外墙生成**：
   - 南立面：每户的客厅大窗 + 卧室窗
   - 北立面：每户的厨房窗 + 卫生间窗
   - 东西山墙：实墙或少量窗
6. **阳台生成**：南向客厅外挂阳台
7. **空调机位**：每户2-3个空调机位
8. **屋顶**：平顶+女儿墙 或 坡屋顶
9. **底商**（可选）：底层大开间+卷帘门

## 3. 配置参数设计 (ResidentialConfig)

### 3.1 建筑整体参数
- building_name: 建筑名称
- building_type: "slab" (板楼) / "tower" (塔楼)
- num_floors: 总层数
- floor_height: 标准层高 (2.8-3.0m)
- building_depth: 建筑进深 (10-16m)

### 3.2 户型参数
- units_per_floor: 每层户数 (1-6)
- unit_configs: 每户配置列表
  - unit_type: "1BR" / "2BR" / "3BR" / "4BR"
  - unit_width: 户型面宽 (m)
  - num_bedrooms: 卧室数
  - has_balcony: 是否有阳台
  - balcony_width: 阳台面宽
  - num_ac_units: 空调机位数

### 3.3 核心筒参数
- core_width: 核心筒宽度 (楼梯间+电梯间)
- core_depth: 核心筒进深
- num_elevators: 电梯数量
- staircase_width: 楼梯间宽度

### 3.4 立面参数
- south_window_height: 南向窗高
- south_window_width: 南向窗宽（客厅大窗）
- north_window_height: 北向窗高
- north_window_width: 北向窗宽（厨卫小窗）
- wall_color: 外墙颜色
- window_color: 窗户颜色

### 3.5 阳台参数
- balcony_depth: 阳台进深 (1.5-2.0m)
- balcony_height: 阳台栏杆高度 (1.1m)
- balcony_type: "open" / "enclosed" (开放/封闭)
- balcony_glass_color: 封闭阳台玻璃颜色

### 3.6 空调机位参数
- ac_slot_width: 空调机位宽度 (0.8-1.0m)
- ac_slot_depth: 空调机位深度 (0.4-0.5m)
- ac_slot_height: 空调机位高度 (0.6m)

### 3.7 底商参数
- has_ground_commercial: 是否有底商
- commercial_floors: 底商层数 (1-2)
- commercial_height: 底商层高 (3.5-4.5m)
- shopfront_width: 店面开间

### 3.8 屋顶参数
- roof_style: "flat" / "pitched" (平顶/坡屋顶)
- parapet_height: 女儿墙高度
- pitch_angle: 坡屋顶角度 (20-35度)
